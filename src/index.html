TRUST BOUNDARY

先理解风险，再连接账号

ModuGate 是第三方本地控制与测试工具。网页订阅不等于官方 API 额度，兼容转接也不会消除服务条款、凭证和内容安全风险。

01

上游服务条款

使用 ChatGPT、Claude 等订阅账号进行 API 中转可能违反上游条款，并可能导致账号限制或封禁。

02

请求内容可见

Sub2API 网关需要处理提示词和模型响应。不要把公司机密发送给不可信的第三方网关。

03

凭证集中存储

上游 OAuth Token 和 API Key 集中在服务器端。应启用 HTTPS、强密码、二次验证和访问控制。

04

生产环境稳定性

内部接口会随上游变化。关键业务应使用官方 API，并为测试网关准备限流、备份和故障隔离。

本软件的数据处理方式

  • API 请求由 Electron 主进程直接发送到你配置的网关。
  • 用户 API Key 使用系统安全存储加密后写入本机配置。
  • 不会自动上传配置，也不会在渲染页面暴露 Node.js 能力。
  • 真实 CLI 通过无 Shell 参数方式启动，输出仅显示在本机。
